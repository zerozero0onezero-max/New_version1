# Bettypatchright

هذا هو مجلد التشغيل المحمول الكامل لخدمة Beatrice Bot. يحتوي على:

- `requirements.json`: سجل واحد للغة التشغيل، الأدوات، الإصدارات، الاعتمادات، واجهة المستخدم، المتصفح، والملفات المطلوبة.
- `environment-check.mjs`: فحص مبكر فعلي للملفات والأوامر وإصدارات حزم Node.js، مع تقرير بالنواقص.
- `browser-runtime.mjs`: تنزيل Chromium المؤجل وتشغيله مرة واحدة عند الحاجة.
- `server.mjs`: خادم التشغيل المستقل وواجهة API الخاصة بـ Patchright.
- `ui/`: نسخة واجهة Beatrice Bot المبنية والمضمنة داخل الحزمة المحمولة.
- `source/`: نسخة المصدر الكاملة للواجهة وإعدادات Vite للمراجعة وإعادة البناء.
- `prepare-ui.mjs`: يبني الواجهة وينسخها إلى `ui/` عند تجهيز نسخة التوزيع.
- `package.json`: اعتماد التشغيل المحمول هو Patchright فقط؛ مكتبات الواجهة مدمجة داخل ملفات `ui/`.

## التشغيل

```bash
npm install
npm run check
npm start
```

يبدأ الخادم بفحص البيئة والملفات والاعتمادات تلقائياً. إذا كان اعتماد Node.js ناقصاً يحاول إصلاحه تلقائياً، ويمكن تعطيل ذلك فقط عبر `BETTYPATCHRIGHT_AUTO_INSTALL=0`. إذا بقي نقص حرج بعد الإصلاح يتوقف الخادم ويطبع السبب.

الخادم المحمول لا يستعير حزم Node.js من مجلدات أعلى أو من مشروع آخر. عند تشغيله في استضافة جديدة، ينفذ تثبيت `package.json` داخل `Bettypatchright` ثم يعيد الفحص؛ لذلك يجب رفع `package.json` مع بقية ملفات هذا المجلد، ولا حاجة لرفع `node_modules`.

لا يتم تضمين Chromium داخل المشروع؛ يبدأ تنزيله بعد فتح الخادم، ويُعاد استخدامه في التشغيلات اللاحقة إذا بقي مجلد كاش Patchright موجوداً. مكتبات Linux المطلوبة مسجلة في التقرير وفي `Dockerfile`، لأن التطبيق لا يستطيع تثبيتها بأمان على كل أنواع الاستضافات.

لتجهيز الحزمة بعد تعديل الواجهة:

```bash
npm run prepare-ui
```

## الاستضافة

يُفضّل تشغيل `node Bettypatchright/server.mjs` بعد تثبيت الاعتمادات. يجب توفير مجلد الواجهة المبنية عبر:

```bash
node Bettypatchright/server.mjs
```

يمكن تجاوز واجهة `ui/` عند الحاجة باستخدام `BETTYPATCHRIGHT_UI_DIR=/path/to/dist/public`.
